# Business Task Platform

MVP-платформа для взаимодействия бизнеса и студенческих команд.

Платформа помогает представителю бизнеса превратить первоначальное описание проблемы в структурированную задачу с помощью AI-ассистента, оценить готовность задачи к работе и опубликовать её в общем каталоге.

Студенческие команды могут просматривать опубликованные задачи и предлагать свои решения. Бизнес самостоятельно выбирает подходящее предложение.

## Основной сценарий

```text
Описание проблемы
        ↓
AI задаёт уточняющие вопросы
        ↓
Формируется карточка задачи
        ↓
Рассчитывается рейтинг готовности
        ↓
Бизнес подтверждает задачу
        ↓
Задача публикуется в каталоге
        ↓
Команда предлагает решение
        ↓
Бизнес принимает или отклоняет предложение
```

## AI-ассистент

Бизнес начинает с произвольного описания своей проблемы или потребности.

AI:

1. анализирует описание;
2. определяет недостающую информацию;
3. задаёт минимум 3 уточняющих вопроса;
4. использует ответы для формирования структурированной карточки задачи.

AI не должен придумывать факты, которые не были предоставлены пользователем. Перед публикацией сформированную карточку можно отредактировать и необходимо подтвердить.

## Карточка задачи

Карточка содержит:

* название;
* контекст и потребность;
* пользователей;
* доступные данные и материалы;
* ограничения;
* ожидаемый результат;
* критерии успеха;
* контакт и формат взаимодействия.

## Рейтинг готовности

Каждая задача получает рейтинг от `0` до `100`, показывающий, насколько хорошо она подготовлена для начала работы.

| Параметр               |   Баллы |
| ---------------------- | ------: |
| Контекст и потребность |      20 |
| Данные и материалы     |      20 |
| Ожидаемый результат    |      15 |
| Критерии успеха        |      15 |
| Ограничения            |      10 |
| Пользователи           |      10 |
| Связь с бизнесом       |      10 |
| **Всего**              | **100** |

Уровни готовности:

| Рейтинг | Уровень      |
| ------: | ------------ |
|    0–39 | Черновик     |
|   40–69 | Рабочая      |
|   70–89 | Готовая      |
|  90–100 | Приоритетная |

Рейтинг пересчитывается после изменения информации о задаче.

## Каталог

После подтверждения задача появляется в общем каталоге.

Команды могут:

* просматривать доступные задачи;
* видеть рейтинг готовности;
* фильтровать задачи;
* сортировать задачи по рейтингу;
* открывать полную карточку;
* отправлять предложение по решению.

Низкий рейтинг не запрещает командам откликаться на задачу.

## Предложения команд

Предложение содержит:

* команду;
* идею решения;
* краткий план;
* предполагаемый срок;
* ссылку на прототип при наличии.

Бизнес видит поступившие предложения и вручную принимает или отклоняет их.

AI не выбирает исполнителя автоматически.

## Scope MVP

Основная цель — реализовать полностью работающий end-to-end сценарий.

В MVP не требуются:

* полноценная регистрация;
* восстановление пароля;
* сложная ролевая модель;
* чат;
* уведомления;
* календарь;
* файловое хранилище;
* собственная ML-модель;
* vector database / RAG;
* мобильное приложение;
* production-инфраструктура.

Для демонстрации роли Business и Team могут переключаться без полноценной системы авторизации.

## Критерий готовности

MVP считается готовым, если можно полностью пройти следующий сценарий:

```text
Business вводит первоначальное описание
→ AI задаёт уточняющие вопросы
→ Business отвечает
→ формируется карточка
→ рассчитывается рейтинг
→ Business редактирует и подтверждает карточку
→ задача появляется в каталоге
→ Team открывает задачу
→ Team отправляет предложение
→ Business получает предложение
→ Business принимает или отклоняет его
```

Все этапы этого сценария должны реально работать в приложении.
