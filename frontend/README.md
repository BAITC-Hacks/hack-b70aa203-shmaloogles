# Мост — frontend

Nuxt 4 / Vue 3 / TypeScript интерфейс платформы, подключённый к Go REST API.

## Локальный запуск

Сначала запустите PostgreSQL и API из корня проекта, затем frontend:

```bash
npm install
npm run dev
```

Приложение доступно на `http://localhost:3000`. Browser API URL задаётся через
`NUXT_PUBLIC_API_BASE` и по умолчанию равен `http://localhost:8080`.

Для полного запуска рекомендуется использовать корневую команду:

```bash
docker compose up --build
```

## Проверки

```bash
npm run typecheck
npm run build
```

## Данные и роли

Задачи, рейтинг, команды и предложения загружаются из backend и хранятся в
PostgreSQL. Backend является единственным источником истины. В браузере
сохраняются только выбранная демонстрационная роль и команда, поскольку MVP не
требует полноценной аутентификации.

Основные маршруты:

| Маршрут | Назначение |
| --- | --- |
| `/tasks/new` | AI-уточнение и создание карточки |
| `/tasks/:id/edit` | Редактирование, рейтинг, подтверждение и публикация |
| `/tasks` | Все задачи бизнеса |
| `/catalog` | Опубликованные задачи, фильтры и сортировка |
| `/catalog/:id` | Карточка и отправка предложения |
| `/tasks/:id/proposals` | Отклики на задачу |
| `/proposals` | Все предложения и ручное решение бизнеса |
